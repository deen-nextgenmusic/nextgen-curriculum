# NextGen DJ Curriculum

Internal tutor handbook for NextGen Music Group Ltd. Not for distribution.

- `src/content/` holds the words: one file per stage, in a simple plain-text format.
- `src/build.py`, `src/dg.py` and `src/illus.py` turn that into the designed page, diagrams and illustrations.
- `docs/` is the published website (served by GitHub Pages), including offline support.

To update: edit the content files, run `./build.sh`, then commit and push. The site updates within a few minutes.
